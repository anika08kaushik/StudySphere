# Contributing

1. Never push directly to `main`.
2. Work on a feature branch from `develop`.
3. Pull `develop` before starting work.
4. Open pull requests into `develop`.
5. Discuss changes to another member's module first.
6. Follow the API and naming conventions.
7. Never commit `.env` files or secrets.
8. Run tests, lint, and builds before pushing.
9. Keep commits focused.

## Branches

Use `feature/member1-identity-groups`, `feature/member2-collaboration`, `feature/member3-productivity`, or `feature/member4-resources-ai` as applicable.

## Local setup

From a fresh clone, run `npm install` in both `frontend` and `backend`, copy each `.env.example` to `.env`, then run both `npm run dev` commands.
